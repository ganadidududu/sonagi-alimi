# 잠금화면 위젯 디자인 스펙 — 소나기 알리미

> 범위: **iOS 잠금화면(Lock Screen) 위젯만.** 홈 화면 위젯·StandBy는 이 문서에 포함하지 않음(향후 확장 섹션 참고).
> 관련 앱 코드: `UbiWeather/Models/WeatherModels.swift`(`WeatherCondition`), `UbiWeather/Design/UbiColors.swift`, `UbiWeather/Services/KMAParsing.swift`(`evaluateAlert`)

## 1. 목적

앱을 열지 않아도 **"지금 우산이 필요한가"**를 잠금화면에서 바로 확인시키는 것. 홈 화면 배너("킬러 기능")를 잠금화면까지 확장하는 개념이므로, 위젯의 우선순위도 배너와 동일하게 **소나기/비 임박 여부**를 최우선으로 둔다.

## 2. 위젯 패밀리

| 항목 | 값 |
|---|---|
| Family | `.accessoryRectangular` 1종만 지원 |
| 배치 위치 | 잠금화면 시계 아래 위젯 영역 |
| 크기 | 시스템 고정 (약 2행 텍스트 + 좌측 아이콘) |
| 미지원 | `.accessoryCircular`, `.accessoryInline` — 3번 섹션 "향후 확장" 참고 |

## 3. 콘텐츠 상태 정의

위젯은 항상 아래 5개 상태 중 하나를 표시한다. 상태 판정 로직은 앱의 `KMAParsing.evaluateAlert` + `peakPrecipWindowText`(30% 임계값)와 **완전히 동일한 기준**을 그대로 재사용한다(별도 로직 만들지 않음).

| 상태 | 트리거 조건 | 1행(제목) | 2행(부제) |
|---|---|---|---|
| A. 소나기 임박 | 다음 2시간 내 `.shower` 슬롯 존재 | `🌦 소나기 임박` | `오후 3시~4시 · 13분 후` |
| B. 비 임박 | 다음 2시간 내 `.rain` 슬롯 존재 (소나기 아님) | `🌧 비 예정` | `오후 5시~6시 · 42분 후` |
| C. 안심(저위험) | 오늘 남은 시간대 최고 강수확률 < 30% | `☀️ 비 걱정 없어요` | `22° · 흐림` |
| D. 로딩/자리표시자 | 위젯 갤러리 미리보기, 데이터 fetch 전 | (redacted 블록) | (redacted 블록) |
| E. 오류/위치 없음 | 앱 미실행·권한 거부로 공유 데이터 없음 | `📍 앱에서 위치를 설정해 주세요` | `탭하여 열기` |

- 상태 A/B의 문구는 홈 화면 알림 배너(`AlertLevel.shower`/`.rain`)의 `windowText`, `minutesUntil`을 그대로 가져다 쓴다 — 배너와 위젯이 다른 표현을 쓰면 안 됨.
- 상태 C는 이번 세션에 홈/시간별 탭에 추가한 "강수확률 낮음" 문구(§`peakPrecipWindowText`)와 톤을 맞춘다.

## 4. 레이아웃 (accessoryRectangular)

```
┌───────────────────────────────────┐
│  ⛅   🌦 소나기 임박                │   ← 아이콘(SF Symbol, 좌측 고정)
│       오후 3시~4시 · 13분 후        │   ← 1행: 상태 제목 (semibold)
└───────────────────────────────────┘   ← 2행: 세부 정보 (regular, 보조)
```

- 아이콘: 좌측 세로 중앙 정렬, 약 34×34pt (2026-07 조정 — 24pt는 실기기에서 너무 작아 보임)
- 텍스트: 아이콘 우측, 2줄 좌측 정렬
- 좌우 여백 없음 — 시스템이 잠금화면 위젯 컨테이너의 인셋을 자동 적용하므로 커스텀 padding 최소화
- 배경: 없음(투명). `containerBackground(for: .widget) { Color.clear }`만 지정 — 나머지는 시스템이 담당

## 5. 타이포그래피

| 요소 | 폰트 | 굵기 |
|---|---|---|
| 1행 (상태 제목) | `.system(.headline, design: .rounded)` | semibold |
| 2행 (세부 정보) | `.system(.caption)` | regular |

- 텍스트는 항상 **1행 1문장, 2행 1문장** — 줄바꿈/말줄임(`...`) 발생 시 정보가 잘리므로 아래 §8 글자수 예산을 반드시 지킬 것.
- 커스텀 폰트(Jua 등 앱 본문 폰트) 사용 금지 — 잠금화면은 시스템 폰트만 렌더링을 보장.

## 6. 색상 / 렌더링 모드

잠금화면 위젯은 iOS가 강제로 단색(vibrant/accented) 처리하므로 **커스텀 색상은 대부분 무시된다.** 아래 규칙만 적용:

- 렌더링 모드: `.accented` (iOS 17+ 잠금화면 기본값)
- `.widgetAccentable()` 를 붙일 요소 = 아이콘 + 1행 텍스트 (사용자가 잠금화면에서 고른 강조색으로 표시됨)
- `.widgetAccentable()` **붙이지 않을** 요소 = 2행 텍스트 (시스템이 자동으로 더 낮은 불투명도의 보조 톤 처리)
- 앱의 `UbiColors`(primaryBlue, deepNavy 등) 커스텀 hex는 잠금화면에서 적용 안 됨 — 디자인 검토 시 하드코딩 색 넣지 말 것
- 다크/라이트 모드 별도 대응 불필요 (시스템이 배경에 맞춰 자동 처리)

## 7. 아이콘 매핑

기존 `WeatherCondition.sfSymbol`을 그대로 재사용(신규 아이콘 제작 없음):

| 상태 | WeatherCondition | SF Symbol |
|---|---|---|
| 소나기 임박 | `.shower` | `cloud.sun.rain.fill` |
| 비 임박 | `.rain` | `cloud.rain.fill` |
| 안심(맑음 계열) | 현재 `currentIcon` 값 그대로 | `sun.max.fill` / `cloud.sun.fill` / `cloud.fill` |
| 오류/위치 없음 | 전용 | `location.slash` |
| 로딩 | — | 심볼 없이 redacted 사각 블록 |

## 8. 카피 규칙 (글자수 예산)

잠금화면 rectangular 위젯의 실사용 가능 폭 기준, 시스템 폰트(headline/caption)에서 잘리지 않는 대략적 상한:

| 행 | 최대 글자수(한글 기준) | 비고 |
|---|---|---|
| 1행 | 약 12자 | 이모지 1개 포함 |
| 2행 | 약 16자 | 시간 범위 + "N분 후" 조합 |

- 시간 표기는 홈 배너와 동일하게 **"오전/오후 N시"** 형식 사용(24시간 표기 금지) — 잠금화면은 화면을 스치듯 보는 맥락이라 12시간제가 더 빨리 읽힘
- "N분 후"는 60분 초과 시 생략하고 시간대만 표시(예: `오후 3시~4시`)

## 9. 데이터 소스 & 갱신

- 잠금화면 위젯은 자체 네트워크 호출을 하지 않는다. 메인 앱이 KMA API를 갱신할 때마다 **App Group 공유 저장소**에 최신 스냅샷(온도, 조건, POP, 알림 상태, 갱신 시각)을 기록하고, 위젯 타임라인 갱신을 트리거하는 구조.
- 위젯은 그 스냅샷만 읽어 렌더링 — 표시 문구/아이콘/임계값 로직은 항상 앱 본체와 100% 동일해야 하므로 별도 파싱 로직을 만들지 않고 공유 모듈을 통해 재사용.
- 스냅샷이 too stale(예: 3시간 이상 경과)한 경우 상태 E(오류) 대신 "N시간 전 정보"라는 별도 안내를 더할지는 구현 단계에서 결정.

## 10. 접근성 (VoiceOver)

화면에는 축약 문구만 보이지만, VoiceOver는 전체 문장을 읽어야 한다.

| 상태 | accessibilityLabel |
|---|---|
| A | "13분 후 오후 3시부터 4시까지 소나기가 예상됩니다" |
| B | "42분 후 오후 5시부터 6시까지 비가 예상됩니다" |
| C | "오늘 강수확률이 낮아 비 걱정이 없습니다. 현재 기온 22도, 흐림" |
| E | "위치가 설정되지 않았습니다. 앱을 열어 위치를 설정해 주세요" |

## 11. 엣지 케이스

| 케이스 | 처리 |
|---|---|
| 앱을 한 번도 실행 안 함(공유 데이터 없음) | 상태 E 고정 표시 |
| 위치 권한 거부 | 상태 E, 탭 시 앱의 위치 권한 안내 화면으로 딥링크 |
| 네트워크 오류로 마지막 갱신 실패 | 마지막 성공 스냅샷 유지 표시(오프라인 홈 화면과 동일 정책) |
| 자정 넘어가 날짜 바뀜 | 다음 타임라인 리로드 시 "오늘" 기준 재계산 |
| 위젯 갤러리에서 미리보기 | 상태 D, redacted 플레이스홀더 |

## 12. 향후 확장 (이번 스코프 아님)

- `.accessoryCircular` — 강수확률 게이지 원형, 홈 화면 잠금 대신 워치용/보조 위젯으로 고려
- `.accessoryInline` — 시계 옆 한 줄, 문구를 §8보다 더 축약해야 함(약 20자 전체)
- 홈 화면(`.systemSmall/.systemMedium`) 위젯 — 잠금화면 스펙 확정 후 별도 문서로 분리
