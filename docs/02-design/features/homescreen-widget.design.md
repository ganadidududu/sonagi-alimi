# 홈 화면 위젯 디자인 스펙 — 소나기 알리미 (6시간 예보)

> 범위: **iOS 홈 화면(Home Screen) 위젯, `systemMedium`(가로긴 중간) 1종.**
> 잠금화면 위젯(`accessoryRectangular`, 단색)과 **별개**임 — 이 위젯은 **풀컬러** 가능.
> 관련 앱 코드: `UbiWeather/Models/WeatherModels.swift`(`WeatherCondition`, `HourlySlot`),
> `UbiWeather/Components/WeatherIconView.swift`(얼굴 날씨 아이콘), `UbiWeather/Design/UbiColors.swift`

---

## 1. 목적 & 잠금화면 위젯과의 차이

| | 잠금화면 위젯(기존) | **홈 화면 위젯(이 문서)** |
|---|---|---|
| Family | `accessoryRectangular` | **`systemMedium`** |
| 색상 | iOS가 **단색(흰색) 강제** | **풀컬러 자유** ✅ |
| 정보량 | 한 줄 요약 | **6시간 시간별 예보 + 알림 배너** |
| 아이콘 | SF Symbol(단색) 권장 | **앱의 귀여운 얼굴 아이콘 그대로** |

**핵심:** 홈 화면 위젯은 색 제한이 없으니, 앱 본체(홈 탭)의 밝은 하늘색 톤 + 얼굴 날씨 아이콘을 그대로 살려서 "앱을 안 열어도 6시간 흐름을 한눈에" 보여준다.

---

## 2. 위젯 크기 (정확한 치수)

`systemMedium`은 **가로 2 × 세로 1 칸** 고정 크기. 기기별로 포인트 수가 다르므로, **디자인 기준 캔버스**를 정하고 상대 배치로 그린다.

### 기준 디자인 캔버스 (이 사이즈로 그리면 됨)
| | 포인트(pt) | @2x 픽셀 | @3x 픽셀 |
|---|---|---|---|
| **기준(iPhone 15/16 Pro)** | **338 × 158 pt** | 676 × 316 px | **1014 × 474 px** |

> **작업은 @3x = 1014 × 474 px 로 그리는 걸 추천.**

### 기기별 실제 크기 (참고 — 반응형으로 늘어남)
| 기기 폭 | systemMedium (pt) |
|---|---|
| 430pt (Pro Max) | 364 × 170 |
| 402pt (16 Pro) | 348 × 159 |
| 393pt (15/16 Pro) | **338 × 158 (기준)** |
| 375pt (SE/mini) | 329 × 155 |

**규칙:** 절대 픽셀 하드코딩 금지. 좌우/상하 **비율(%)과 flex 간격**으로 배치해서 위 범위에서 안 깨지게.

### 시스템이 알아서 하는 것 (디자인에서 신경 X)
- **바깥 모서리 라운드**: iOS가 자동으로 ~**22pt** 둥글게 깎음 → 코너에 중요한 요소 두지 말 것
- **배경**: `containerBackground`로 채움 (아래 §6 배경 규칙)
- 위젯 전체가 **탭하면 앱 열림**(딥링크 가능) — 위젯 안에 버튼 여러 개는 불가

## 3. 레이아웃 (와이어프레임 + 치수)

가로로 길고 세로가 짧으므로 **위: 알림/헤더 스트립(1줄) / 아래: 6시간 컬럼**의 2단 구조.

### 3-A. 알림 있을 때 (소나기·비 임박)
```
┌───────────────────────────────────────────────────────────┐ 338×158pt
│ ▸ 상단 배너 (h 34pt, 좌우 full, accent 그라디언트, 라운드 12)│
│   🌦  소나기 임박 · 오후 3시~4시 · 13분 후                  │
├───────────────────────────────────────────────────────────┤ ← 간격 10pt
│   지금    15시    16시    17시    18시    19시              │ ← hour (11pt)
│   ⛅      🌦      🌦      🌧      ☁      🌤                │ ← 아이콘 (34pt)
│   26°     25°     24°     24°     25°     26°               │ ← 기온 (15pt bold)
│  💧20%   💧80%   💧75%   💧55%   💧20%   💧10%             │ ← 강수 (10.5pt)
└───────────────────────────────────────────────────────────┘
     └─ 6컬럼 균등분할, 각 ~51pt, 세로 중앙정렬
```

### 3-B. 알림 없을 때 (평상시)
상단 배너 자리에 **현재 요약 헤더**를 넣음:
```
┌───────────────────────────────────────────────────────────┐
│ 📍 마포구 서교동                    지금 26° · 흐림          │ ← 헤더 (h 30pt)
├───────────────────────────────────────────────────────────┤
│   지금    15시    16시    17시    18시    19시              │
│   ⛅      🌤      ☀      ☀      ⛅      ☁                │
│   26°     27°     28°     27°     26°     25°               │
│  💧20%   💧10%   💧0%    💧0%    💧20%   💧30%             │
└───────────────────────────────────────────────────────────┘
```

### 여백 규칙
- 위젯 안쪽 콘텐츠 패딩: **좌우 14pt, 상하 12pt**
- 상단 배너/헤더 높이: **30~34pt**
- 배너 ↔ 시간별 줄 간격: **10pt**
- 6컬럼 사이 간격: 균등(스페이스 비트윈), 각 컬럼 내부는 세로 정렬(hour→icon→temp→precip), 요소 간 **4~5pt**

## 4. 콘텐츠 상태 (5가지)

| 상태 | 조건 | 상단 스트립 | 6시간 컬럼 |
|---|---|---|---|
| A. 소나기 임박 | 2시간 내 `.shower` | 🌦 배너(accent), "소나기 임박 · 시간 · N분 후" | 정상 표시 |
| B. 비 임박 | 2시간 내 `.rain` | 🌧 배너(accent), "비 예정 · 시간 · N분 후" | 정상 표시 |
| C. 평상시 | 위 아님 | 헤더(위치 · 지금 온도 · 상태) | 정상 표시 |
| D. 로딩/플레이스홀더 | 갤러리 미리보기 | 스켈레톤 | 스켈레톤 6칸 |
| E. 위치 없음 | 앱 미실행 | "앱에서 위치를 설정해 주세요" | 빈 상태 + 탭 유도 |

- A/B 배너 문구는 **잠금화면 위젯·홈 배너와 동일한 표현** 사용 (일관성). 시간은 12시간제("오후 N시").
- 강수확률 **가장 높은 컬럼**은 살짝 강조(배경 틴트 or 굵게) 해서 눈에 띄게 — 소나기 컬럼 하이라이트.

## 5. 타이포그래피

폰트: **앱 본문 폰트(Jua) 사용 가능** — 홈 화면 위젯은 커스텀 폰트 OK (잠금화면과 달리). 숫자는 가독성 위해 시스템 rounded도 무방. 아래는 기준(pt는 338 캔버스 기준).

| 요소 | 크기 | 굵기 | 색 |
|---|---|---|---|
| 배너 제목("소나기 임박") | 13pt | semibold | 흰색 |
| 배너 부제(시간·N분 후) | 11.5pt | regular | 흰색 85% |
| 헤더 위치명 | 12pt | semibold | `textBody` |
| 헤더 현재요약("지금 26° · 흐림") | 12.5pt | medium | `textSub` |
| 시간 라벨(지금/15시) | 11pt | semibold | `textMuted` |
| 기온(26°) | 15pt | bold | `textBody` |
| 강수확률(💧20%) | 10.5pt | bold | `primaryBlue` |

## 6. 색상 / 배경 (풀컬러 — 앱 톤 그대로)

앱 홈 탭의 밝은 하늘 톤을 그대로 계승.

### 배경 (containerBackground)
- 평상시: 앱 홈 그라디언트 계열 세로 그라디언트
  - `#8BA6C8 (0%) → #AEC3DC (45%) → #DBE6F0 (100%)` (앱 `UbiSky.home`과 동일)
  - 또는 더 밝게: `#DBE6F0 → #EEF3F8` (텍스트 대비 원하면)
- **다크 모드**: 딥네이비 계열 `#2F4A6D → #24354B` + 텍스트/아이콘 밝게 (라이트/다크 둘 다 디자인)

### 팔레트 토큰 (앱 `UbiColors`)
| 토큰 | HEX | 용도 |
|---|---|---|
| primaryBlue | `#4A90E2` | 강수확률, 포인트 |
| deepNavy | `#2F4A6D` | 진한 텍스트/다크 배경 |
| textBody | `#3F5670` | 기온 등 본문 |
| textSub | `#5B7690` | 보조 텍스트 |
| textMuted | `#8598AE` | 시간 라벨 |
| 배너 accent(앰버) | `#F9A94A → #F4832F` | 소나기/비 배너 그라디언트 |

### 배너 색
- 소나기/비 배너는 앱 홈의 **알림 배너와 같은 앰버 그라디언트**(`#F9A94A→#F4832F`) + 흰 텍스트 + 소프트 섀도.

## 7. 아이콘

**앱의 얼굴 달린 둥근 날씨 아이콘(`WeatherIconView`)을 그대로 사용.** (잠금화면과 달리 색 유지됨)
- 자연색: 해 `#FFCF5A`, 구름 흰색, 빗방울 `#7FB4EC`, 이목구비는 각 톤 짙은색
- 6시간 컬럼 아이콘 크기: **34pt** (작아서 얼굴은 생략하고 심플 버전, 앱 타임라인 카드와 동일 규칙)
- 상태별: 맑음/구름조금/흐림/약한비/소나기 (앱 `WeatherCondition` 5종)

---

## 8. 데이터 (구현 참고)

- 표시 데이터: **현재(위치·기온·상태) + 향후 6시간(시간·아이콘·기온·강수확률)**
- 소스: 앱이 KMA 초단기예보를 받아 **App Group 공유 저장소**에 6시간 슬롯을 저장 → 위젯이 읽음.
  - (알림 한 줄만 저장하던 기존 잠금화면 스냅샷보다 **더 풍부한 6슬롯 데이터**가 필요 — 구현 시 스냅샷 모델 확장)
- 위젯 갱신은 서버 캐시(`getWidgetWeather`) 경유 또는 App Group 스냅샷 — KMA 직접 호출 금지(트래픽).

## 9. 접근성 (VoiceOver)

전체를 하나의 요약으로 읽되, 핵심 먼저.
- A: "13분 후 오후 3시부터 4시까지 소나기 예상. 이후 6시간 예보: 지금 26도 흐림, 15시 25도 소나기…"
- C: "마포구 서교동, 현재 26도 흐림. 6시간 예보: …"
