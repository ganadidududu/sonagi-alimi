# Handoff: 우비 (Ubi) — 소나기 알림 날씨 앱

## Overview
"우비"는 기상청 초단기예보 기반으로 **2시간 내 비/소나기를 미리 알려주는** 모바일 날씨 앱입니다.
킬러 기능은 홈 화면 최상단의 **알림 배너**로, "언제부터 언제까지 비/소나기가 오는지"를 색+아이콘 이중 신호로 압도적으로 강조합니다.
주 타깃은 도보/자전거 출퇴근족(원핸드 모바일, 빠른 확인)입니다.

## About the Design Files
이 번들의 `ubi-weather-reference.html` 은 **HTML로 만든 디자인 레퍼런스(프로토타입)** 입니다 — 의도한 외관·동작을 보여주는 참고물이지, 그대로 이식하는 프로덕션 코드가 아닙니다.
**목표: 이 디자인을 SwiftUI로 새로 구현하는 것** 입니다. SwiftUI의 관용적 패턴(`View`, `@State`/`@Observable`, `NavigationStack` 또는 `TabView`, `.animation`, SF Symbols/커스텀 에셋)을 사용해 네이티브로 재현하세요. HTML/CSS 구조를 문자 그대로 옮기지 마세요.

브라우저에서 `ubi-weather-reference.html` 을 열면 왼쪽 컨트롤 패널로 **모든 화면과 상태**를 전환하며 볼 수 있습니다.

## Fidelity
**High-fidelity.** 최종 색상·타이포·간격·인터랙션이 확정된 목업입니다. 아래 디자인 토큰과 화면 스펙을 그대로 SwiftUI로 재현하세요.

## 플랫폼 전환 시 핵심 결정 (웹 → SwiftUI)
브리프는 원래 Next.js/PWA 기준이었으나 **네이티브 iOS(SwiftUI)** 로 전환합니다. 따라서:

- **PWA 설치 유도 배너 → 삭제하거나 "알림 권한 요청(priming)" 프롬프트로 대체.** 네이티브 앱에는 홈 화면 설치 개념이 없습니다. 대신 킬러 기능(비 알림)을 살리려면 `UNUserNotificationCenter` 권한 요청 화면이 필요합니다. 레퍼런스의 PWA 배너 자리를 이 용도로 재활용하세요.
- **위치**: `CLLocationManager`. 권한 거부 상태(레퍼런스의 "위치 거부" 화면)를 반드시 구현.
- **날씨 데이터**: 기상청 초단기예보 API를 직접 호출하거나(브리프 요구), 프로토타이핑 단계에서는 Apple **WeatherKit** 로 대체 가능. 아래 "데이터 모델" 참고.
- **폰트**: 웹은 Google Fonts(Jua, Noto Sans KR). SwiftUI에서는 **Jua.ttf 를 번들에 포함**(둥근 귀여운 디자인의 핵심)하고, 없으면 `Font.system(.title, design: .rounded)` 로 폴백. 본문은 시스템 폰트(San Francisco / Apple SD Gothic Neo).
- **아이콘**: 커스텀 "얼굴 달린 둥근 날씨 아이콘"이 브랜드 정체성입니다. SF Symbols(`cloud.sun.rain.fill` 등)로 시작하되, 여유가 되면 커스텀 에셋으로 얼굴·볼터치까지 재현 권장. 아래 "아이콘 의미" 참고.

## 아이콘 의미 (중요)
커스텀 날씨 아이콘은 5종이며 각각 다음을 뜻합니다. SF Symbols 매핑 병기:

- **sunny (맑음)** — 얼굴 있는 해. `sun.max.fill`
- **partly (구름 조금)** — 작은 해 + 흰 구름. `cloud.sun.fill`
- **cloudy (흐림)** — 회색 구름. `cloud.fill`
- **rain (비)** — 회색 구름 + 파란 빗방울 3개. `cloud.rain.fill`
- **shower (소나기 = sun shower)** — **작은 해 + 구름 + 빗방울 4개.** 해가 남아있는 상태에서 잠깐 지나가는 비를 뜻함. 앱의 킬러 상태(🌦 소나기 예정)와 직결. `cloud.sun.rain.fill`
- 홈 아이콘들은 위아래로 살짝 떠다니는 bob 애니메이션(3~3.6s ease-in-out infinite).
- 브랜드 디테일: 큰 아이콘(배너·현재날씨)의 구름에는 **눈·미소·볼터치**가 있음 → 커스텀 에셋으로 재현 권장.

## Screens / Views

### 1. 홈 (Home) — 최우선
현재 위치 헤더 → **알림 배너(킬러)** → 현재 날씨 카드 → 시간별 예보(가로 스크롤) → 오늘·내일·모레 → (선택)알림 권한 배너.
- **알림 배너**: 화면 최상단 큰 카드. 액센트 그라디언트, "🌦 소나기 예정" 펄스 배지, 큰 아이콘 + "오후 3시~4시 30분 / 소나기가 지나가요", "약 13분 뒤 시작 · 우산을 꼭 챙기세요". 상단에 지나가는 shine 하이라이트(4.5s).
- **현재 날씨 카드**: 반투명 흰 카드. 큰 기온(62pt) + "흐림·곧 비·체감 21°" + 아이콘. 하단 3칩(습도/바람/강수확률).
- **시간별 가로 스크롤**: 66pt 폭 카드. 시각·아이콘·기온·💧%. 소나기 시간대는 흰 카드+주황 테두리로 하이라이트.
- **오늘·내일·모레**: 리스트 행(요일·아이콘·상태·💧%·최저·최고).

### 2. 시간별 (Hourly) — 6시간 타임라인
상단 요약 배너("15~16시 강수확률 80%") + 시각별 리스트 행. 각 행: 시각·아이콘·상태·💧%(+미니 확률 바)·기온.

### 3. 일별 (Daily) — 주간
7일 리스트. 요일/날짜·아이콘·💧%·최저—최고 **온도 범위 바**(그라디언트 `#7FC8F0 → #F4A13C`, min~max 대비 좌우 오프셋 계산). 오늘 행 하이라이트.

### 4. 레이더 (Radar)
격자 지도 위 강수 blob(파랑=약, 주황=강, ubi-blob 5s 애니메이션) + 내 위치 핀 + 하단 재생 컨트롤/타임 슬라이더 + 강도 범례(약함→강함 그라디언트 바).

### 5. 설정 (Settings)
- 지역: "현재 위치로 설정" 버튼(파랑) + 동/읍/면 검색 + 저장된 지역 리스트(현재 배지).
- 알림: 마스터 토글 + 소나기 알림 + 비 알림(강수확률 60%+) + 방해금지(22:00~07:00). 토글 on=`#3AA76D`.
- 화면: 다크 모드 토글(현재 "준비 중").

### 상태 화면 (모두 구현 필수)
- **로딩**: 홈 레이아웃 형태의 스켈레톤 + 시머.
- **오프라인**: 상단 스트립 "오프라인 · 마지막 업데이트 14:32 · 캐시된 정보" + 캐시 데이터 표시.
- **에러/데이터 없음**: 중앙 슬픈 비 아이콘 + "날씨를 불러오지 못했어요" + 다시 시도 버튼.
- **위치 권한 거부**: 핀 아이콘 + 설명 + 지역 검색 입력 + "위치 권한 다시 요청" 버튼.
- **알림 권한 요청(구 PWA 자리)**: "알림 켜고 비 소식 먼저 받기" 프롬프트.

## Interactions & Behavior
- 하단 탭바 5개(홈/시간별/일별/레이더/설정) — 활성 색 `#2F4A6D`, 비활성 `#9AABC0`. SwiftUI `TabView`.
- 배경 그라디언트는 탭/날씨에 따라 0.6s로 크로스페이드.
- 애니메이션: 아이콘 bob(3s), 빗방울 낙하(0.75~1.35s), 배너 shine(4.5s), 소나기 배지 pulse(2.2s), 카드 등장 fadeUp(0.5s, ease-out).
- 설정 토글은 즉시 상태 반영(로컬 상태).
- 빗방울 오버레이는 홈/시간별에서만, 감성용(모션 줄이기 옵션 제공 권장 → `Reduce Motion` 존중).

## 데이터 모델 (기상청 초단기예보 → 앱)
초단기예보(getUltraSrtFcst) 주요 카테고리:
- `T1H` 기온(℃), `REH` 습도(%), `WSD` 풍속(㎧), `RN1` 1시간 강수량
- `PTY` 강수형태: **0 없음 / 1 비 / 2 비·눈 / 3 눈 / 4 소나기(← shower, 강조)**
- `SKY` 하늘: 1 맑음 / 3 구름많음 / 4 흐림
- (강수확률 POP는 단기예보 카테고리 — 초단기에는 없으므로 RN1·PTY로 대체 판단하거나 단기예보 병행)

**아이콘 매핑**: PTY=4→shower, PTY∈{1,2}→rain, PTY=3→snow(추가 필요), PTY=0 & SKY=1→sunny, SKY=3→partly, SKY=4→cloudy.
**배너 상태 로직**: 향후 2시간(6구간) 예보 중 PTY≠0 이 있으면 배너 표시. PTY=4 이면 "소나기 예정"(강조 액센트), PTY∈{1,2}이면 "비 예정"(파랑), 전부 0이면 배너 없음("알림 없음"). 시작~종료 시각을 배너 문구에 표기.
