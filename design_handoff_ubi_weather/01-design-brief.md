# weather-app 디자인 브리프 (프로토타입 의뢰용)

> 원본 PRD: `docs/01-plan/features/weather-app.plan.md`
> 이 문서만 넘겨도 프로토타입 제작에 충분하도록 PRD에서 핵심만 추출했습니다.

## 제품 한 줄 요약

"우산 챙길지 고민하지 마세요. 비 오기 전에 앱이 먼저 알려드립니다."
기상청 초단기예보 기반, **2시간 내 소나기/비를 미리 알려주는** 날씨 PWA.

## 타깃 사용자 (우선순위)

1. **도보/자전거 출퇴근족** (주 타깃) — 원핸드 모바일, 짧고 빠른 확인
2. 야외 활동 계획자 — 시간대별 상세 확인이 필요
3. 일반 날씨 확인 사용자 — 아침에 훑어보는 용도

## 디자인 화면 목록 (우선순위 순)

| 순위 | 화면 | 핵심 목적 |
|---|---|---|
| 1 | **홈** | 현재 날씨 + "2시간 내 알림 상태" 배너 — 킬러 기능, 가장 눈에 띄어야 함 |
| 2 | **6시간 타임라인** | 가로 스크롤 카드, 시간별 아이콘+기온+강수확률 |
| 3 | 오늘/내일/모레 요약 → 상세 | 일반 날씨 정보 |
| 4 | 레이더 | 전국 합성영상 애니메이션 |
| 5 | 지역 설정 | GPS 버튼 + 행정구역 검색 |
| 6 | 알림 설정 | on/off, 비 가능성 옵션, 방해금지 시간대 |

**우선 화면 1개만 디자인해야 한다면 → 1번 홈 화면.**

## 홈 화면에 실제로 표시될 데이터

- 기온(T1H), 습도, 풍속, 강수형태 아이콘
- 알림 배너 — 아래 3가지 상태를 시각적으로 구분:
  - 🌦 소나기 예정 (강조, 가장 눈에 띄게)
  - 🌧 비 예정
  - ☀️ 알림 없음 (평상시)
- "몇 시부터 몇 시까지" 시간 정보가 배너에 바로 보여야 함

## 반드시 디자인해야 하는 상태 (state)

- 로딩 스켈레톤
- 오프라인 배지 (마지막 캐시 데이터 + "오프라인" 표시)
- 에러 / 데이터 없음
- 위치 권한 거부 시 대체 화면 (지역 검색 유도)
- PWA 설치 유도 배너

## 톤 & 스타일 방향 (PRD에 미정 — 프로토타입 제작자가 정하거나 옵션 제시 요청)

- 모바일 퍼스트 (PWA), 데스크톱은 보조 레이아웃
- 밝고 직관적인 날씨 아이콘 중심, 정보 위계 명확
- 알림 배너는 **색상 + 아이콘 이중 신호**로 (접근성 요구사항, 색맹 사용자 고려)
- 다크모드 지원 여부 — 미정, 프로토타입에서 선택지로 제안받기

## 기술 제약 (디자인 시 고려)

- Next.js 15 + Tailwind CSS
- iOS Safari 포함 실기기 타겟
- 알림 배너·타임라인 카드는 재사용 가능한 컴포넌트 단위로 설계

## 프로토타입 의뢰 시 요청 문구 예시

```
아래 브리프 기준으로 모바일 앱 프로토타입을 만들어줘.
우선순위: 1) 홈 화면(알림 배너 포함) 2) 6시간 타임라인 3) 나머지 화면.
스타일은 밝고 직관적인 날씨 앱 톤으로, 다크모드 옵션도 하나 제안해줘.
[브리프 내용 붙여넣기]
```
